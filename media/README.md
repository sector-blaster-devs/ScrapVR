# Hand-tracking demonstration

[Watch or download the hand-tracking demo](hand-tracking-demo.mp4).

![Side-by-side stereo hand-tracking frame](hand-tracking-demo.jpg)

This recording demonstrates experimental hand tracking in a PC-rendered stereo scene. The application shown is a demonstration environment; its source and assets are not part of ScrapVR.

The tracker can lose the head marker and hand placement remains experimental. This clip is evidence of a development attempt, not a claim of production-ready tracking.
